# Aredoko（あれどこ）

**名前を忘れたファイルを、覚えていることから探せる。**

Aredokoは、PCにある画像・本・同人誌・動画・音声をまとめて探せる、Windows向けのローカル検索アプリです。ファイル名やタグで探せるほか、AI検索を有効にすると「青い夜空のイラスト」のような曖昧な日本語からも探せます。

## できること

- **探す** — ファイル名・タグで検索。AI検索では、画像の見た目や動画の一場面を手がかりに似た素材を探せます。
- **見る** — 見つけた画像や本を開き、動画や音声をアプリ内で再生できます。
- **整理する** — タグ・棚・お気に入りで管理できます。原本はそのまま、整理した情報はPC内のカタログに保存します。

## はじめ方

Windows x64向けです。公開版の配布は準備中です。配布開始後は[GitHub Releases](https://github.com/jakymiku/Aredoko/releases)で入手できます。

1. 配布ZIPを展開し、`Aredoko.exe` を開きます。初回は案内に沿って基本環境をダウンロードします。
2. 探したいフォルダを登録し、**アイテム一覧だけ取得**を選ぶと、ファイル名・タグで検索できます。
3. AI検索を使う場合は、設定からAI環境とモデルを準備し、登録フォルダのAI索引を作成します。

詳しい操作と動作条件は[利用ガイド](docs/user-guide.md)をご覧ください。
