# Aredoko 利用ガイド

Aredoko（あれどこ）は、指定フォルダの画像・本・動画・音声を名前/タグで探し、整理・閲覧するローカルアプリです。AI環境を準備すると、画像の見た目、本のページ、動画の代表フレームも検索できます。音声内容の自動索引は開発中です。

## 起動と保存先

開発環境では `tools/start-winui.ps1` を使います。現在のx64ビルドと実際の配備ファイルが違う場合は起動失敗を明示します。

`tools/package_release.py` の出力は配布準備用stagingです。`Aredoko.cmd` / `start-aredoko.ps1` を含みますが、PythonとAI依存/モデルを同梱していません。開発ツールのないWindowsでのidentity/ランタイム/起動・更新・アンインストール受入は未完です。完成したインストーラーとして扱わないでください。

カタログの既定保存先は `%LOCALAPPDATA%\Aredoko`。独自DBや設定を起動引数で指定している場合は、その保存先もバックアップ対象です。原本は読み取り専用で、タグ/棚/履歴はDBへ保存します。

## 登録・検索・閲覧

1. 左側の「登録フォルダ」または「フォルダ管理」からフォルダを追加します。初期棚・サブフォルダを含めるか・除外ルールを指定できます。
2. 最初は「名前・タグ」で検索します。「画像の見た目（AI）」は画像/表紙/索引済みページ/動画代表フレーム、「名前・タグの意味（AI）」は登録された文字情報、「両方で探す（AI）」はその融合です。
3. 一覧から選択して詳細でタグ/棚/お気に入りを編集し、保存します。ダブルクリックや詳細ボタンから対応ビューワーを開きます。

フォルダの追加は走査を行います。内容の変更を取り込むときは対象フォルダの再スキャンを実施します。自動常時監視が完成しているとは案内しません。

画像/本は拡大表示・ページ移動、本は見開き方向や読書位置に対応。動画はシークや代表フレームの一致時刻へ移動できます。音声/曲は名前・タグ検索と再生が利用できます。保存済み音声特徴を検索する接続もありますが、録音内容/曲調の自動解析はまだ通常索引に接続していません。コーデックやファイルの破損により再生できない場合があります。

画像・本の静止ページは、2048pxへ縮小せず元の解像度で読み込みます。「原寸」で100％表示、「画面に合わせる」で全体表示へ戻れます。倍率は元画像に対する比率です。小さい画像は初期表示で引き伸ばしません。通常の表示完了/再生説明文は出さず、読み込み中や失敗時のみ通知します。アニメーションは別のフレーム処理を使います。

## 一覧の表示サイズ

「表示サイズ」のスライダー、または一覧上の **Ctrl＋マウスホイール** で、サムネイルとカードの大きさを60〜180％（20％刻み）に変更できます。通常のホイールはスクロールです。リスト/グリッドのどちらでも使え、文字の大きさは維持します。

サイズは次回の起動にも引き継がれ、「標準に戻す」で100％へ戻せます。タグの編集中もサイズを変更できます。ウィンドウが縦に短い場合は、名前を表示する余地を残すためサムネイルの高さを抑えます。

## AIの準備と継続

モデルや依存を無断で自動取得しません。現在使用するEmbeddingGemma 2は `google/embeddinggemma-2`、プロジェクトでは768D設定です。WD Taggerは `wd-swinv2-tagger-v3`。導入条件/ライセンス/固定版は [モデル設定](model-profiles.md) と [WD Tagger](wd-tagger.md)を確認してください。音声の直接入力能力や追加モデルの方式は実測評価が残っています。

1回の索引jobは最大10,000件です。設定の明示継続で未準備分を進め、途中で中断したときも保存済み索引を再利用できます。検索時の全集合と1jobの処理上限は別です。GPUメモリのアイドル解放は設定可能で、手動解放もできます。

専用OCRは保留しています。生成14枚/17問では画像内文字も直接画像ベクトルで検索できましたが、あらゆる実画像で読める保証ではありません。実例で漏れが多い場合に再検討します。

## バックアップと新規先への復元

Aredokoを終了してから、配布フォルダまたはリポジトリ直下で実行します。以下はPowerShellの例です。出力先は存在しない新規フォルダを指定します。

```powershell
python tools/backup_library.py backup --catalog "$env:LOCALAPPDATA\Aredoko\catalog.sqlite" --output "D:\AredokoBackup\new-backup"
python tools/backup_library.py restore --bundle "D:\AredokoBackup\new-backup" --output "D:\AredokoRestored\new-library"
```

AI/viewer設定や独自profileも保存する場合は [復旧手順](backup-recovery.md) の設定用オプションを付けます。新規復元先の検証後、復元DB/設定を明示して起動します。実DBへの上書き復元や処理の自動再開はしません。

## 規模と受入の範囲

生成50,001件のメタデータと65,536ベクトルで規模試験を実施済みです。実私物1TB全体の索引・品質や全端末の応答速度を保証するものではありません。音声実解析、最新小窓UI/High Contrast/DPI/Narrator、clean環境配布の受入が残ります。現状は [ブラッシュアップ監査](polish-audit-20261020.md) を参照してください。
