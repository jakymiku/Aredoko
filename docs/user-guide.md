# Aredoko 利用ガイド

Aredoko（あれどこ）は、指定フォルダの画像・本・動画・音声を探し、整理・閲覧するローカルアプリです。まずはAIなしでファイル名・タグ検索を使えます。任意のAI環境と索引を準備すると、画像・本のページ・動画・音声の内容からも探せます。

このガイドは2026-10-29以降の開発版向けです。以前のAlphaには新しい画面・機能が含まれない場合があります。起動中の版は「設定」→「診断情報」で確認できます。

## まずはAIなしで使う（3ステップ）

1. ZIP全体を解凍して **Aredoko.exe** を開きます。
2. **登録フォルダ → フォルダを追加 → 登録** と進み、登録後の確認で **アイテム一覧だけ取得** を選びます。「後で」を選んだ場合は、そのフォルダの設定から一覧を取得できます。
3. **ファイル名・タグ** で検索し、見つけた作品をダブルクリックして開きます。タグや棚の編集は一覧の「詳細」から行えます。

情景・会話・音の特徴で探したくなったら、下の「任意AIの初回設定」へ進んでください。AIを準備する前から閲覧と整理は使えます。

## ZIP版の起動と保存先

**ZIP全体を解凍し、Aredoko.exeを開きます。** EXEだけを移動せず、同梱フォルダを一緒に保持してください。基本機能のPython・動画用ツールとWinUI実行に必要なファイルを同梱しています。モデルとAI実行環境は別です。

起動中は進捗画面を表示し、問題があればログへの案内を表示します。通常利用はAredoko.exe、専用の空データで起動を確認したい場合だけCheck-Startup.cmdを使います。バックエンドを別途手動で起動する必要はありません。

ショートカットが古い版を指している場合があります。更新後は新しい解凍先のAredoko.exeで確認してください。開発作業用のtools/start-winui.ps1は通常の起動手順ではありません。開発環境のないWindows全般での受入はまだ完了していません。

カタログの既定保存先は `%LOCALAPPDATA%\Aredoko`。独自DBや設定を起動引数で指定している場合は、その保存先もバックアップ対象です。原本は読み取り専用で、タグ/棚/履歴はDBへ保存します。

## 登録・検索・閲覧

1. 左側の「登録フォルダ」または「フォルダ管理」からフォルダを追加します。初期棚・サブフォルダを含めるか・除外ルールを指定できます。
2. 最初は「ファイル名・タグ」で検索します。「画像の見た目（AI）」は画像/表紙/索引済みページ/動画代表フレーム、「ファイル名・タグの意味（AI）」は登録された文字情報、「両方で探す（AI）」はその融合です。
3. 一覧から選択して詳細でタグ/棚を編集し、保存します。新しい開発版ではお気に入りはチェック変更で即時保存され、右クリックからも切り替えられます。ダブルクリックや詳細ボタンから対応ビューワーを開きます。

フォルダ登録後は「アイテム一覧だけ取得」「一覧取得＋AI索引を作成」「後で」を選べます。後から登録フォルダの設定でスキャンもできます。起動時の一覧更新・AI処理はフォルダごとに選択できます。常時監視する機能ではありません。

登録フォルダの「設定」では、一覧取得を上部から実行できます。初期棚・除外ルール・起動時の動作・登録解除は、見出しを開いて変更します。初期棚と除外ルールはそれぞれの保存ボタンで保存し、起動時の動作は変更した時点で保存されます。パネルを閉じても編集中の値は残ります。別のフォルダや画面へ移る場合は、未保存の変更を確認します。

フォルダ追加は、場所と「サブフォルダを含める」を指定するだけで登録できます。初期棚・除外・画像フォルダを本としてまとめる指定は「追加の設定」にあります。複数のパスは `;` で区切って入力できます。キャンセルは入力を保持して欄を閉じます。一部だけ登録できなかった場合は、未登録のパスと指定内容を残すので、内容を確認して再試行してください。

画像・本は拡大表示・ページ移動、本は見開き方向や読書位置に対応します。動画・音声はシークや検索一致時刻への移動に対応します。開発版ではファイル名はウィンドウのタイトルに表示されます。操作バーは下端へマウスを移すと表示され、通常は約1秒で隠れます。F10またはTabでキーボード操作に移れます。画像・本の「操作バーを常に表示」は動画・音声にも反映されます。コーデックやファイル状態によって再生できない場合があります。

画像・本は元解像度で読み込み、「原寸」で100％、「画面に合わせる」で全体表示に戻せます。小さい画像の拡大・操作バー表示・本の先頭末尾ループは、ビューア内の設定ボタンまたは右クリックで変更します。ホイール方向はAredokoの設定で選べます。

開発版のプレイヤーでは、音量スライダーにフォーカスを置くと左右キーで音量を変更でき、消音などのボタンではSpaceでそのボタンを操作できます。再生画面上のSpaceは再生・一時停止です。画像・本の設定メニューを開いている間は、後ろの画像やページへ移動しません。

「設定」→「ダブルクリックで開くアプリ」でWindowsの既定アプリも選べます。外部アプリにはAredokoの検索順位・連続閲覧順を引き継ぎません。詳細の表示ボタンは内蔵ビューアを使うので、いつでも内蔵表示に戻れます。

一覧下部の「読み込み済み」は、現在読み込んでいる結果の範囲です。スクロールで続きが読み込まれます。「一覧の操作」から前後の範囲の読み込みや接続・一覧更新も行えます。選択件数は、表示外の作品を含む全選択を示します。

AI未導入の検索画面では「AIの準備へ」で用途選択を開くか、「ファイル名・タグで探す」で同じ検索語の文字検索へ戻れます。

## 外観と整理

設定でライト/ダーク/Windowsに合わせるを選び、保存すると反映します。グリッド/リストの表示方法と表示サイズは、次回起動でも維持します。登録フォルダから対象を絞ったときは、検索対象フィルタの表示と解除ボタンが出ます。

棚を開くと所属アイテムを表示します。複数選択したアイテムの右クリックから、棚やお気に入りをまとめて設定できます。詳細は一覧の「詳細」または右クリックから開きます。タグ・棚は保存、お気に入りは変更するとすぐ保存されます。

「設定 → 使い方・初回設定」は最初の3手順を表示します。「フォルダの登録へ」から登録画面へ進め、細かな操作やデータ保護は「詳しい手順・操作とデータ保護」を展開して確認できます。

新しい開発版では、お気に入りフォルダの行の「…」または右クリックから、フォルダの設定を開いたり、お気に入りから外したりできます。お気に入りから外してもフォルダの登録や元ファイルは残ります。アイテムのタグを編集中に設定へ移る場合は、変更を破棄するかを確認します。

棚の所属を選ぶ画面では、棚名で絞り込めます。表示されなくなった選択は保持され、選択件数と表示外の件数を確認できます。「適用」で詳細へ戻り、「保存」で確定します。キャンセルでは所属を変更しません。

## 一覧の表示サイズ

「表示サイズ」では **小・中・大** を選べます。スライダー、または一覧上の **Ctrl＋マウスホイール** で、サムネイルとカードの大きさを60〜180％（20％刻み）に変更できます。通常のホイールはスクロールです。新しい開発版のグリッドは幅に合わせて列数とカード幅を調整します。リスト/グリッドのどちらでも使え、文字の大きさは維持します。

サイズは次回の起動にも引き継がれ、「標準に戻す」で100％へ戻せます。タグの編集中もサイズを変更できます。ウィンドウが縦に短い場合は、名前を表示する余地を残すためサムネイルの高さを抑えます。

## 任意AIの初回設定

初回の案内、または「設定」→「使い方・初回設定」→「使いたいAI機能から準備」を開きます。意味検索・類似画像・動画・音声を複数選び、「必要な環境を確認」を押します。共有する検索用モデルは重複して取得しません。「今はAIを使わず始める」も選べ、後から再設定できます。

モデルの取得と、AIを動かす実行環境の準備は別です。「モデルの取得候補を見る」で容量・取得元・ライセンスを確認してから取得を開始します。実行環境の自動配布はまだ準備中です。「配置済みの環境・モデルを指定」で確認済みの環境を選べます。モデルだけを取得してもAIは動きません。環境を変更したら再起動し、「設定」→「AI検索の準備」で各媒体の索引を作成してください。

AIの取得・配置画面を閉じると初回設定ガイドへ戻り、現在の状況と次の手順を確認できます。モデル選択や環境の変更を保存した場合は、案内に従ってAredokoを再起動してください。取得済みでも、使用する保存先の設定と索引作成は別途必要です。

うまく使えない場合は、ガイドの「うまく使えないとき」を開くと、モデルの版違いやファイル不足などに応じた案内と診断情報への入口があります。この案内から元ファイルや索引の削除・初期化は行いません。

## モデルの取得

「AI検索の準備」→「モデルをダウンロード」で取得候補を確認できます。容量・進捗・速度、中止・再開に対応し、速度は既定で無制限です。必要な場合だけ「速度制限」を展開し、上限を指定します。手動配置も選べます。モデルの取得と実行環境の導入は別で、取得済みでも索引を作成するまでは内容検索に使えません。[モデル配置の詳細](model-acquisition.md)も参照してください。

## AIの準備と継続

モデルや依存を無断で自動取得しません。現在使用するEmbeddingGemma 2は `google/embeddinggemma-2`、プロジェクトでは768D設定です。WD Taggerは `wd-swinv2-tagger-v3`。導入条件/ライセンス/固定版は [モデル設定](model-profiles.md) と [WD Tagger](wd-tagger.md)を確認してください。音声の直接入力能力や追加モデルの方式は実測評価が残っています。

1回の索引jobは最大10,000件です。設定の明示継続で未準備分を進め、途中で中断したときも保存済み索引を再利用できます。検索時の全集合と1jobの処理上限は別です。GPUメモリのアイドル解放は設定可能で、手動解放もできます。

専用OCRは保留しています。生成14枚/17問では画像内文字も直接画像ベクトルで検索できましたが、あらゆる実画像で読める保証ではありません。実例で漏れが多い場合に再検討します。

## 動画の内容から探す

1. 動画を含むフォルダを登録し、アイテム一覧を取得します。
2. 「設定」→「AI検索の準備」で「動画の内容検索」を展開し、「動画の索引を作成」を押します。中断しても、完了した動画は次の作成で再利用します。
3. 検索方法を「動画の内容（AI）」にして場面や特徴を入力します。一致した区間が表示され、内蔵プレイヤーは一致開始時刻から開きます。

準備済み動画を右クリックして「内容が似た動画を探す」と、双方の一致区間がある候補を探せます。従来の「似た動画・素材を探す」は代表フレームを比較する別の入口です。動画内の音声は直接動画索引の対象外です。長い動画同士や大量候補の比較では範囲上限があるため、フォルダや棚で対象を絞ってください。実動画に対する検索品質は引き続き評価中です。

## 動画内の音声から探す（新しい開発版）

「設定」→「AI検索の準備」→「動画内の音声」で索引を作成し、検索方法の「動画内の音声（AI）」から会話や音の特徴を文章で探せます。映像の索引とは別で、先頭の音声トラックが対象です。音声のない動画は飛ばします。文字起こしは保存しません。

準備済み動画を右クリックして「音が似た動画を探す」と、保存済みの音声索引だけで似た動画を探します。結果には起点と候補の一致区間が表示されます。映像から探す「内容が似た動画を探す」や、音声ファイルから探す機能とは別の入口です。音声と動画内音声の索引作成は同じ処理枠を使うため、一方の準備中は完了を待つか、その対象の準備欄から中断してください。

動画内音声の機能は現在の開発ソースへ追加済みです。インストール済みAlpha（基本ZIP10）にはまだ含まれません。実際の録音・曲・動画への検索品質や、複数トラック選択は引き続き確認・開発中です。

## 音声の内容から探す（新しい開発版）

1. 音声を含むフォルダを登録し、一覧へ取り込みます。必要なら登録フォルダや棚から検索対象を絞ります。
2. 「設定」→「AI検索の準備」で「音声の内容検索」を展開し、「音声の索引を作成」を押します。準備済みの音声は再利用されます。残りがある場合は、もう一度作成すると続きへ進みます。
3. 検索方法を「音声の内容（AI）」にして、覚えている内容や音の特徴を文章で入力します。結果には一致した時刻が表示され、その時刻から音声を再生できます。

準備中も画面を閉じられます。止める場合は音声の準備欄の「中断」を押してください。文字起こしは生成しません。録音や曲調すべてに対する検索品質は引き続き改善中です。音声の文章検索は基本ZIP07に含まれます。新しい開発版では、準備済みの音声を右クリックして「内容が似た音声・曲を探す」を選ぶと、一致時刻付きの候補を表示できます。この比較は作成済み索引を使い、元の音声やモデルを読み直しません。旧来の音響特徴による類似検索も保持しています。内容による音声類似検索は、現在のAlpha（基本ZIP10）に含まれます。

## バックアップと新規先への復元

「設定」→「バックアップと復元」から、アプリを起動したまま作成できます。ライブラリ情報に加え、設定・履歴・読書位置・AI索引の対象を選べます。元のメディア・モデル・AI実行環境は含みません。

復元は新しい保存先で検証し、同意した再起動で切り替えます。元ライブラリを上書きせず保持します。未保存編集や処理中の作業があれば画面の案内に従ってください。

起動できない場合だけ、停止中に復旧ツールを使えます。以下は開発環境向けのPowerShell例です。通常利用では画面の操作を優先してください。

```powershell
python tools/backup_library.py backup --catalog "$env:LOCALAPPDATA\Aredoko\catalog.sqlite" --output "D:\AredokoBackup\new-backup"
python tools/backup_library.py restore --bundle "D:\AredokoBackup\new-backup" --output "D:\AredokoRestored\new-library"
```

AI/viewer設定や独自profileも保存する場合は [復旧手順](backup-recovery.md) の設定用オプションを付けます。新規復元先の検証後、復元DB/設定を明示して起動します。実DBへの上書き復元や処理の自動再開はしません。

## 規模と受入の範囲

生成5万件のライブラリや音声・動画の限定試験を実施しています。実録音・音楽・動画全般の検索品質、全端末の性能、High Contrast/物理DPI、開発環境のないWindowsでの導入は引き続き確認中です。

### 2026-10-21の試験配布の状態

このPCでは許可済みの試験証明書信頼とAlpha版の通常インストールが完了し、既存開発版と併存しています。入口は**配布に対応するAredoko Alphaショートカット**です。MSIX単体のメニュー項目を全体の起動入口として案内しません（Python側の起動も必要です）。生成画像の登録・検索・タグ保存まで確認済みですが、閲覧・正常終了/再起動・開発環境のないWindowsでの受入は未完了です。

添付された「Windows app activation failed」は、保存成功の表示をテストが取り違え、中断時の終了を旧launcherが起動失敗と表示したものです。ソースの通知分類とテストを修正しました。通常利用のエラー通知は維持しています。automation用の`--no-error-dialog`は明示したときだけダイアログを省略し、ログと失敗終了は残します。現在の封印済み02配布へは修正を直接書き込んでいません。[実機結果と残る作業](alpha-packaged-activation.md)を参照してください。
