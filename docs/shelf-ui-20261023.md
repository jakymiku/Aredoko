## 到達点

既存version1の移行/APIを再利用。CoreにShelfDescriptor/ShelfClient、MediaRow.ShelfIds（64bit）、構造比較する棚draftと反射不要JSONを追加。棚nav→名前/件数/代表画像/空棚の一覧→同じ共通libraryへ接続。作成/名前変更/削除と右詳細の複数選択を追加した。適用後は通常の保存で確定し、キャンセル/未保存確認を維持する。棚削除は所属だけを消し、作品と原本は残す。

通常/本文/候補検索はshelf_idsでOR、別条件とはAND。semantic/similarはscope.shelf_filter_idsを追加し、保存済みshelf/shelf_idsも残してANDする。複数所属なのでID集合の単純積集合では代用できない。この追加はリクエスト用で、保存済みAI設定を書き換えない。既存scope JSONの省略形はそのまま。
