# Aredoko WinUI 3 — UI整合性・アクセシビリティ検証チェックリスト (R10 / R11)

本書は [プロダクトビジョン](product-vision.md) および [WinUI 3 デザイン方針](design-vision-winui.md) に基づき、日常利用における表示の一貫性、状態の明瞭性、キーボード操作性、アクセシビリティ、および高DPI・テーマ対応の検証基準を定義する。

---

## 1. 状態表示とガイダンスの分離基準 (Status Clarity Matrix)

AI未導入、未索引、対象外、処理失敗と「0件ヒット（検索結果なし）」を混同させず、常に具体的かつ実用的な日本語ガイダンスを提供する。

| 状態コード (`status_code` / `search_status`) | 発生要因 | 表示メッセージ (`Empty.Text` / `Notice`) | ユーザー推奨アクション |
|---|---|---|---|
| `model_missing` / `ai_unavailable` | AIモデルまたはPython venvが未導入 | 「AI環境（モデル・Python）が未導入です。名前・タグの文字検索、棚・整理、閲覧はそのまま利用できます。」 | 通常の文字検索を利用するか、設定からAI環境をセットアップする。 |
| `unindexed` | 検索対象範囲に対象アイテムはあるが、AI索引が0件 | 「選択範囲の作品はAI索引がまだ作成されていません（対象 N件・未索引）。「設定」→「AI検索の準備」から索引を作成してください。」 | 設定ダイアログからAI索引を作成・継続する。文字検索は即座に利用可能。 |
| `partially_indexed` | 検索対象範囲の一部のみ索引済み | 「選択範囲の一部のみ索引済みです（N件中 M件完了）。残りの作品は「設定」→「AI検索の準備」から索引を追加できます。」 | 必要に応じて追加索引を実施。 |
| `out_of_scope` | 選択されたフォルダ・絞り込みに対象アイテムが0件 | 「選択されたフォルダ・絞り込みに対象作品がありません。検索フォルダや種類の条件を確認してください。」 | フォルダ選択や種類（本/画像/動画/音声）の条件を見直す。 |
| `worker_failed` | AI推論プロセスが異常終了/切断 | 「AI推論プロセスが停止または失敗しました。文字検索は利用できます。「設定」からAI状態を確認・再開してください。」 | アプリ再起動または設定からAIプロファイル・索引を確認。 |
| `insufficient_space` | 検索用一時領域またはディスク容量不足 | 「検索用の一時作業領域の空き容量が不足しています。ドライブの空き容量を確認してください。」 | ドライブの空き容量を確保して再試行。 |
| `port_conflict` | バックエンド通信ポートの衝突 | 「ポートの競合が発生しました。他のインスタンスが起動していないか確認してください。」 | 既存のバックグラウンドプロセスを確認。 |
| `search_cancelled` | ユーザーによる検索中断操作 (ボタンまたはEsc) | 「検索を中断しました。」(InfoBar: 情報) | 再度検索または条件変更。 |
| `ready` (0件一致) | 索引済みだがクエリに一致する候補なし | 「「{query}」に一致するAI候補はありませんでした。別の言葉で検索するか、名前・タグ検索をお試しください。」 | 別の同義語や表現で検索、または通常文字検索を試す。 |

## 2. 用語・ラベルの統一 (Terminology Alignment)

全画面・ダイアログ・ビューワー間で用語を統一し、技術的内部IDやテスト用の長文を通常画面に露出させない。

- **検索方法**:
  - `名前・タグ` (通常文字検索)
  - `両方で探す（AI）` (意味と見た目のRRF統合検索)
  - `画像の見た目（AI）` (表紙・代表フレームの視覚特徴)
  - `名前・タグの意味（AI）` (メタデータ言語意味検索)
  - `未承認タグ候補` (WD等による未承認タグ一覧)
  - `ページ本文` (抽出済みページテキストの全語一致検索)
  - `タグ候補の意味（AI）` (未承認タグの埋め込み検索)
- **メディア種類**:
  - `本`, `画像`, `動画`, `音声`, `ZIP`, `素材`
- **操作ボタン**:
  - `検索` (`BtnSearch`, AccentButtonStyle)
  - `中断` (`BtnCancelSearch`, 検索処理中のみ動的表示)
  - `フォルダ管理` (`BtnRoots`)
  - `グリッド表示` / `リスト表示` (`BtnLayout`)
  - `詳細` (`BtnDetails`)
  - `設定` (`BtnSettings`)

## 3. テーマ・外観・狭幅レスポンシブ検証 (Theme & Layout Matrix)

### A. Light / Dark テーマ
- [x] **Lightテーマ**: コントラスト比 4.5:1 以上を確保。テキストの視認性、選択枠（Selection Indicator）、アクセントカラーの可読性。
- [x] **Darkテーマ**: チャコール〜ダークグレー背景。作品画像の邪魔をしない落ち着いた階層表示。
- [x] **High Contrast (ハイコントラストモード)**: Windowsハイコントラストテーマ時にシステムカラー（`SystemColorWindowTextColor`, `SystemColorHighlightColor` 等）が適用され、枠線とフォーカスが明瞭。

### B. 狭幅レイアウト (< 800px)
- [x] 詳細ペイン（SplitView）がオーバーレイ（ドロワー）表示に自動切り替え。
- [x] 検索バー、種類コンボ、検索方法コンボが折り返して横スクロールを発生させない。
- [x] スクロールガター（余白）がサムネイルやボタンの操作を妨げない。

### C. 高DPI対応 (100%〜200%)
- [x] `app.manifest` で `PerMonitorV2` DPI認識が明示され、拡縮時にテキストやアイコンがぼやけない。
- [x] サムネイル生成（`ThumbnailCodec`）が高DPI環境でも適切なピクセル密度で描画。

## 4. キーボードナビゲーション & アクセシビリティ (Keyboard & Narrator)

### A. キーボードショートカット
- `Ctrl + F`: 検索入力ボックス（`Query`）に即座にフォーカスを移動。
- `Ctrl + S`: 詳細編集パネルの内容を保存（未保存変更がある場合）。
- `Escape`:
  - 検索処理中の場合: 進行中の検索を直ちに中断（`BtnCancelSearch` と同等）。
  - 詳細パネルが開いている場合: パネルを閉じる。
- `Tab / Shift + Tab`: 検索ボックス → 検索ボタン → 中断ボタン（表示時） → 種類 → 検索方法 → リスト/グリッド → 一覧アイテム の論理的順序を維持。
- `Enter / Double-Click`: 選択アイテムのビューワー起動（画像・本・動画・音声）。

### B. スクリーンリーダー (Narrator / UI Automation)
- [x] 全主要コントロールに `AutomationProperties.AutomationId` および `AutomationProperties.Name` を付与。
- [x] 検索結果件数（`TxtCount`）、ページ数（`TxtPageNumber`）、空状態メッセージ（`TxtEmpty`）が支援技術から正しく読み上げ可能。
- [x] エラーやガイダンスは `InfoBar` を通じて通知。

## 5. プライバシーと診断情報の安全性 (Redacted Diagnostics)

- [x] **完全任意取得 (Opt-in)**: 設定画面の「診断情報を表示・コピー」からのみ手動で生成。
- [x] **非送信保証**: クラウドや外部サーバーへの自動送信コードは一切存在しない。
- [x] **パスの難読化**: ユーザー名が含まれるパス（`C:\Users\<user>\...`）は `C:\Users\[USER]\...` に自動置換。
- [x] **認証情報の完全除外**: セッショントークン（`Bearer` / `X-Aredoko-Token`）は診断テキストから厳格に除外または `[REDACTED]` 置換。
- [x] **停止時バックアップ案内**: 排他ロックで保護されたDBの安全なオフラインバックアップ手順（`tools/backup_library.py`）を案内。
