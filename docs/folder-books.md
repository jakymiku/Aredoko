# 画像フォルダを「一冊」として扱う（P3 第1縦切り、2026-10-16）

## ユーザー決定（2026-10-16）

- 素材やバラの画像が入ったフォルダは**今まで通り1枚ずつ**のアイテム。
- フォルダ登録時に「**画像フォルダを一冊として扱う**」にチェックしたものだけを一冊にする。
- **自動での振り分け・推測はしない**（フォルダ名、枚数、画像サイズ、連番などから判定しない）。

## 動作

- 登録rootごとの設定 `library_roots.folder_books`（0/1、既存rootは0のまま追加migration）。
- `folder_books=1` のrootをスキャンすると、**画像ファイルを直接含む各ディレクトリ**が1件の `kind:"book"` になる。
  - `relative_path` は末尾 `/`（例 `作品A/`）。登録フォルダ直下の画像は `./`（タイトルは登録フォルダ名）。ファイルパスは末尾 `/` にならないので区別できる。
  - サブフォルダは別の本（`作品B/おまけ/`）。親子をまとめることはしない。
  - 画像以外（動画、PSD、CBZ等）は従来通り1ファイル1アイテム。
  - 除外ルールはページ単位でも適用。リンク/ジャンクションのページは読まない（スキャンでも読書でも）。
- `size_bytes` はページ合計、`mtime_ns` には (名前, サイズ, mtime) の並びのSHA-256由来63bit値を保存。ページの追加・削除・改名・更新で既存のrevision・サムネイルcache key・AI索引revisionが変わる。
- 読書（`/api/library/reader/<id>`）・プレビュー（先頭ページ）・タグ候補生成の入力（先頭ページ）はZIP/CBZと同じAPIで動く。ページ順は自然順（`p1, p2, p10`）。表示可能な形式（png/jpg/webp/gif/bmp）のみページになる。10000ページ超は読書不可。
- 再スキャン前にページが変わると、読書は409（開き直し）、プレビューは不可。再スキャンで**同じアイテムIDのまま**タグ・棚・お気に入りを保持。画像が全部消えたフォルダは `missing`（記録は保持）。
- **設定はスキャン後に変更不可**：切り替えると1枚ずつのアイテムに付けたタグが「見つからない」記録に残り、メタデータが移らないため。未スキャンなら再登録で変更可。再登録で `folder_books` を省略すると以前の設定を維持。

### 読み取り・スキャンの補強（2026-10-16、Linuxで検証）

- 自然順で同順位になる名前は、元のファイル名のUnicode順で固定する（例 `p001.png, p01.png, p1.png`）。ディレクトリ列挙の順番が変わっても、同じrevisionのページ番号・表紙を変えない。ZIP/CBZの既存順序は変更しない。
- 開く直前と読み取り後に、祖先ディレクトリのリンク/ジャンクション・本のディレクトリID・ページの現在パス/handle ID・サイズ/時刻・ページ一覧を再確認する。読み取り中のページ追加/削除・差し替え等を検出したら結果を公開しない。読書は409、プレビューは404。常に変化するファイルシステムの完全なsnapshotや、内容の全hashを保証するものではない。
- 読書manifestだけでなく、プレビュー・タグ由来・タグ入力にも**除外後の直接画像候補10000件**の上限を適用。対応外画像も候補数に含み、10001件目で収集を止める。巨大フォルダの先頭画像だけを別経路で解析しない。スキャン自体は一冊として記録できる。
- スキャンはディレクトリ単位でページ情報をまとめて記録し、root全体のページ一覧をメモリに保持しない。transactionはroot単位を維持し、途中失敗・キャンセル・dry-runでは既存索引と整理情報を変更しない。
- 並び順の修正で古い表紙vector/タグ候補/読書位置を誤再利用しないよう、フォルダ変更検知tokenを`folder-book-v2`へ更新。**以前に一冊モードで索引したrootは一度再スキャンが必要**。同じ作品ID・タグ・棚・お気に入りは維持し、古い読書位置/未承認候補はrevision不一致扱い、AI索引は次回の明示索引で再作成する。単体画像・ZIP/CBZのtokenは変更しない。

## API

- `POST /api/library/roots` に任意の `folder_books: true|false`（boolean以外は400）。
- `GET /api/library/roots` の各rootに `folder_books: bool`。
- 登録時の固定・パスを含まない検証エラー（重複、入れ子、一冊モード変更不可など）は汎用文言でなく具体的な英語`error`で返し、WinUIは`ErrorText`で日本語表示（`PUBLIC_FOLDER_ERRORS`）。

## WinUI

- 登録パネルにチェックボックス `RootFolderBooks`。再登録のprefillで以前の設定を反映。
- 登録フォルダ一覧に「一冊モード」。詳細のパス表示は「作品A/（画像フォルダを一冊として表示）」。
- 一冊は「本を開く」・ダブルクリック・AIタグ候補の対象。
