# メディア内容索引とアイテム起点の類似検索

2026-10-15ユーザー再確認：最終的にはEmbeddingGemma 2を中心に動画・画像・音声/音楽の内容を解析し、検索用データをDBへ蓄積したい。選択したアイテムの右クリック「類似検索」から似た動画・画像・音楽/音声を探す操作も求めている。

## 必須の到達目標

- 名前・タグに加えて内容から曖昧な日本語で横断検索する。登録済みフォルダ/棚による範囲制限、全体検索を両立する。
- 画像の特徴、動画の時間付きシーン、音声/音楽の内容や特徴を出典と対応づけて保存する。動画/音声はアイテム単位と時間区間を区別し、ヒットした場面/音の位置を説明・開けるようにする。
- アイテムから類似候補を取得するAPIと右クリックUIを追加し、種類/フォルダ/棚の絞り込み、自分自身の除外と検索根拠を備える。
- EmbeddingGemma 2の正式な入力仕様を確認して直接扱える形式を使う。扱えない形式ではフレーム抽出、音声認識、音響特徴などの前処理/別モデルを検討する。直接対応を検証なしで約束しない。
- profile/モデルID/revision/前処理versionを索引へ記録する。入替と再索引、取消/再開、資源上限、元データ不変・ローカル処理を維持する。モデル専用アプリへ狭めない。
