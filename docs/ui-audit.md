## 監査で見つかった課題と対処
1. **表示領域** — 元の大きな紹介見出し・英語の装飾ラベル・広い間隔により、一覧の表示可能件数が減っていた。→ 見出しを24pxに縮小し、検索46px・密なツールバー・コンパクトなカードで一覧を広くした。
2. **編集の連続性** — クリックのたびにモーダルが開き、作品を見比べづらかった。→ デスクトップ右固定の詳細・タグ編集パネルと、狭幅での引き出しパネルに変更。
3. **未保存編集** — フィルタ変更・ページ移動・別作品選択で変更内容を失う可能性があった。→ フォームをdirty管理し、移動・閉じる・再読込前に確認する。
4. **フォームの状態** — 保存・読込のフィードバックと入力エラーの表示が弱かった。→ 保存中・エラー・未保存の状態表示、タグ数・長さのクライアント検証、エラーへのフォーカスを追加。
5. **セマンティクス** — キーボード操作、フォーカス表示、クリック対象の分離が不十分。→ スキップリンク、検索ラベル、`aria-pressed`、`aria-busy`、詳細パネルの小画面フォーカス制御を追加。
6. **画像と大量表示** — 元の画像には寸法属性がなく、読み込み優先度の制御が弱かった。→ 固定アスペクト比、`width`/`height`、先頭だけeager・以降lazy、1ページ60件・`content-visibility`を利用。完全な仮想スクロールは未実装。
7. **空状態と通信失敗** — 空結果からの復帰や取得エラーの再試行ができなかった。→ クリアボタン・再試行ボタンを追加。
8. **検索の誤認** — 文字検索を意味検索と混同しない文言を維持。検索条件・ページをURLへ反映（同じタブでの再読み込み用）。

## 今回維持した仕様
API、SQLiteスキーマ、ページ60件、文字検索、種類/表示フィルタ、単体・一括編集、タグ/単一棚/お気に入り/確認済みの永続化。複数選択の一括保存は従来どおりすべての値を置き換え、画面上にも警告を表示する。
