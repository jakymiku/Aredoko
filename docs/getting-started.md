# Aredokoの使い方・初回設定

## まずは登録と閲覧

1. 初回の空ライブラリの「フォルダを登録する」から、検索したいフォルダを選びます。サブフォルダを含めるかも指定できます。登録後、詳細パネルの「選択フォルダをスキャン / 再開」で一覧へ読み込みます。元のメディアは移動・変換しません。
2. 検索欄にファイル名やタグを入力します。AIを導入しなくても文字検索と閲覧が使えます。
3. 画像・本・動画はダブルクリックで開きます。右クリックからエクスプローラーや既定のソフトでも開けます。
4. 右の詳細でタグや棚を編集して保存します。お気に入りはすぐ反映します。棚は左ナビから開けます。

## AI検索を追加する（任意）

「設定」→「AI検索の準備」→「モデルをダウンロード」で容量・ライセンスを確認し、明示的に取得します。EmbeddingGemma 2は画像・文章の検索、WD Taggerは画像のタグ候補用です。既定の取得速度は無制限で、任意の上限を指定できます。

モデルだけではAIは動きません。対応する実行環境も必要です。実行環境の自動取得は現在準備中のため、配置済みの封印packを「配置済みを指定」で選択します。[詳細な配置手順](ai-environment-guide.md)。設定後に再起動し、AI索引の対象を確認して「索引を作成・更新」を実行します。以後「画像の見た目」などの方法で、覚えている情景や特徴を入力して探します。

WDの推定タグは自動で確定タグにはなりません。詳細のAIタグ候補で確認し、必要な候補を承認します。

## 閲覧・設定・バックアップ

一覧ではCtrl+Homeで検索結果の先頭、Ctrl+Endで末尾へ移動できます。文字入力欄の中では通常のカーソル移動になります。画像や本は左右キー・ホイール・マウスの進む／戻るで送れます。ホイールの方向、テーマ、小さい画像の拡大は設定から変更できます。バックアップと復元も設定から行います。棚や登録を解除しても元メディアは削除しません。

使い方は「設定」→「使い方・初回設定」からいつでも開けます。初回案内は登録フォルダのない空ライブラリに自動表示するinline案内で、起動完了を妨げる強制wizardではありません。登録が済むと通常一覧になり、検索失敗時の案内を覆いません。自動スキャン・自動取得は開始しません。
